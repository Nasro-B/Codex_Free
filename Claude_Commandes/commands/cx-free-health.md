# /cx-free-health

Check the standalone Codex Free EN home, LiteLLM port 4200, bridge port 4201 and visible models.

Run:

~~~powershell
pwsh -NoProfile -File "$env:USERPROFILE\.claude\scripts\cx-free.ps1" -Mode health -Model deepseek-flash
~~~

HTTP 402 from a Mina request means the CloudZIR balance is insufficient. It is different from a local proxy failure.
