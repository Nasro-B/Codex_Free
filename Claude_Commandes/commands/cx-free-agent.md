# /cx-free-agent

Launch an explicit Codex agent through the standalone Codex Free EN runtime.

Syntax:

~~~text
/cx-free-agent [model] <mission>
/cx-free-agent [model] --write <mission>
~~~

Supported model names are listed by /cx-free-models. The default is deepseek-flash. The agent is read-only unless --write is explicitly provided.
